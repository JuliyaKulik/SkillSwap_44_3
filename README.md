SkillSwap — Платформа обмена навыками
Дипломный проект, разработанный командой из 12 человек. Платформа позволяет пользователям обмениваться навыками, находить экспертов и развивать профессиональные компетенции.

🛠 Мой вклад в проект
1. Страницы аутентификации
Созданы статические страницы входа и регистрации
Реализована верстка с использованием CSS-переменных
Подключены SVG-иконки (Google, Apple, закрыть)
Настроена маршрутизация между страницами
Добавлены заглушки для кнопок и форм
2. Шторка выбора навыков
Реализовано открытие SkillsSelector по клику на кнопку в хедере
Исправлено отображение иконки лупы в поисковом инпуте
Добавлена анимация открытия/закрытия
Реализовано закрытие по клику вне области
CSS-классы приведены к camelCase
3. Поиск пользователей
Создан компонент поиска с собственной логикой
Поиск по всем строковым полям пользователя (без дубликатов)
Результаты отображаются в модальном окне
4. Рефакторинг страницы пользователя
Вся логика вынесена в хук useSelectedUserPage
Удален mockData, исправлена высота карточки
5. Рефакторинг главной страницы
Исправлено выравнивание стрелок (по центру текста)
Изменен цвет текста в кнопках карточек
Соответствие макету Figma
6. Рефакторинг раздела "Избранное"
Компонент полностью очищен от логики (только пропсы)
Корректная обработка пустого массива
Исправлены стили: паддинги, отступы, центрирование
🛠️ Технологии
React, TypeScript, CSS Modules, CSS-переменные, React Hook Form, Redux Toolkit, React Router, ESLint, Prettier, Vite

## Установка для разработчиков (Внимательно!):

- Клонируйте репозиторий

- Установите зависимости **`npm ci` вместо `npm install`** - это критически важно для одинаковых версий

- Запуск в режиме разработки `npm run dev`

### Проверка что всё работает:

1. Проверка TypeScript
   `npm run type-check`

2. Проверка линтера
   `npm run lint`

3. Проверка стилей
   `npm run lint:styles`

4. Проверка форматирования
   `npm run format:check`

5. Запуск dev-сервера
   `npm run dev`

6. Запуск Storybook
   `npm run storybook`

**Основная команда для проверок**

`npm run type-check && npm run lint && npm run format:check`

#### Технологии проекта на 16.01

- Vite - сборщик

- React 18 + TypeScript - основной стек

- Redux Toolkit - глобальное состояние

- React Router v6 - маршрутизация

- React Hook Form + Yup - формы и валидация

- Axios - HTTP-клиент

- Jest + RTL - тестирование

- ESLint (Airbnb) + Prettier + Stylelint - линтинг

- Storybook - документация компонентов

##### Code Style

- Типизация: Всегда используйте TypeScript типы

- Именование: PascalCase для компонентов, camelCase для остального

##### Рекомендации

**Частые коммиты** - не ждите конца дня, коммитьте каждый завершенный кусок

**Команды для фиксов**

`npm run lint:fix`

`npm run lint:styles:fix`

`npm run format`
